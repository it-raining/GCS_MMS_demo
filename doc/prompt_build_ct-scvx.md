=== MUST READ: THEORY CONTEXT AND SCOPE ===

You do NOT need to implement the full paper “Continuous-time Successive Convexification for constrained trajectory optimization”.

The paper has several components:
1. exterior-penalty reformulation of path constraints,
2. generalized time dilation,
3. multiple-shooting discretization,
4. l1 exact penalization of nonconvex constraints,
5. prox-linear / SCP outer loop with convergence proof.

For this task, implement ONLY item (1) embedded into the repository’s existing multiple-shooting transcription, using the existing RK4 + IPOPT pipeline.

Do NOT implement:
- a new prox-linear algorithm,
- a new SCP outer loop,
- trust regions,
- convexification iterations,
- l1 exact penalization,
- a new solver backend,
- a true mixed-integer solver,
- a full proof-level continuous-time certificate.

Instead, implement:
“CTCS safety integral” = continuous-time constraint satisfaction inspired penalty integral, discretized by RK4 quadrature.

The theoretical object is:

For a path constraint
    g(t, x(t), u(t)) <= 0,

choose a nonnegative exterior penalty q such that:
    q(g) = 0 if g <= 0,
    q(g) > 0 if g > 0.

Then define:
    Lambda(t,x,u) = sum_i q(g_i(t,x,u)).

The paper’s key equivalence is:
    integral Lambda(t,x(t),u(t)) dt = 0
if and only if the path constraints hold almost everywhere, assuming Lambda is nonnegative and continuous/piecewise continuous.

In this repository, the path constraint is geometric region membership:
    pi(x_v(tau)) in Q_v
where
    Q_v = { q : A_v q <= b_v }.

Therefore for each region v:
    residual_i(x) = A_v[i] @ pi(x) - (b_v[i] - safety_margin)
    Lambda_v(x) = sum_i max(0, residual_i(x))^2

The auxiliary state is:
    d eta_v / d tau = Delta_v * Lambda_v(x_v(tau))
    eta_v(0) = 0

Then:
    eta_v(1) = integral_0^1 Delta_v * Lambda_v(x_v(tau)) d tau.

In the ideal continuous-time theory:
    eta_v(1) = 0
implies
    pi(x_v(tau)) in Q_v almost everywhere.

In this implementation:
    eta_v(1) is only an RK4/quadrature approximation.
Therefore never claim exact continuous-time safety.
Report it as:
    “RK4 approximation of accumulated path-constraint violation”.

Use:
    eta_v(1) <= ctcs_tolerance
instead of hard equality eta_v(1) == 0.

Important distinction:
- Mesh safety checks constrain finitely many points:
      A_v pi(x_v(tau_k)) <= b_v - margin
- CTCS integral safety constrains an accumulated nonnegative violation:
      eta_v(1) ≈ integral Lambda_v d tau <= tolerance

CTCS is stronger than node-only checks when the RK4 stages see the violation, but it can still miss narrow inter-stage violations. That is why dense post-checking is required.

=== HOW THIS MAPS TO GCS-MMS ===

The graph/GCS layer chooses a sequence of convex safe regions using relaxed y_uv and p_v variables.

The multiple-shooting layer assigns one local trajectory segment to each active region v:
    s_v^- : entry shooting state
    s_v^+ : exit state
    w_v   : local control parameters
    Delta_v : local duration

Existing continuity/interface constraints:
    s_u^+ = z_uv
    s_v^- = z_uv
    z_uv in Q_u ∩ Q_v

These only ensure valid transition points. They do NOT ensure that the entire local trajectory segment stays inside its assigned convex region.

The CTCS integral must be applied per active local region segment:
    eta_v(1) <= tolerance when p_v = 1.

Do not apply CTCS only to interface variables z_uv.
Do not apply CTCS only to s_v^- and s_v^+.
Do not apply CTCS only to mesh points.

The correct object is the whole local trajectory generated by:
    dx_v/dtau = Delta_v * f(x_v, u_v(tau; w_v))
    x_v(0) = s_v^-

=== COMMON WRONG IMPLEMENTATIONS TO AVOID ===

Wrong:
    Add sum(Lambda) to objective only.
Why wrong:
    Optimizer may trade small collision violation for lower path cost.

Wrong:
    Only enforce eta on selected interface points z_uv.
Why wrong:
    z_uv is a transition state, not the whole local trajectory.

Wrong:
    Replace dynamics endpoint F with an unrelated eta computation.
Why wrong:
    eta must integrate along the same RK4 trajectory used by the defect constraint.

Wrong:
    Enforce eta_end == 0 exactly.
Why wrong:
    IPOPT and RK4 have numerical error; use eta_end <= tolerance.

Wrong:
    Use residual = A@pos - b + margin inconsistently.
Correct:
    Existing mesh code checks A@pos <= b - margin.
    Therefore residual should be:
        A@pos - (b - margin)
    equivalently:
        A@pos - b + margin.

Wrong:
    Forget inactive regions.
Correct:
    For integrated relaxation:
        eta_end <= ctcs_tolerance + ctcs_eta_big_m*(1 - p_v)

Wrong:
    Claim exact guarantee.
Correct:
    This is an RK4 approximation of the continuous-time violation integral, backed by dense post-checking.
